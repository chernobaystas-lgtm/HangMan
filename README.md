Шибениця (Hangman)
Консольна гра «Шибениця», написана на C++ з використанням ООП.
Опис
Комп'ютер обирає випадкове слово зі списку та ховає його за символами підкреслення. Гравець вводить літери по одній, намагаючись відгадати слово до того, як закінчаться спроби. З кожною помилкою малюнок шибениці доповнюється новою деталлю.
Можливості
Слово обирається комп'ютером випадково зі списку.
Список слів зберігається у файлі в зашифрованому вигляді (шифр Цезаря).
Слова не повторюються, поки не буде використано весь список.
Малюнок шибениці змінюється залежно від кількості помилок.A
Перевірка на некоректний ввід (цифри, символи не приймаються).
Повторний ввід тієї самої літери не витрачає спробу.
Після завершення гри виводиться статистика:
витрачений час;
кількість спроб;
загадане слово;
усі введені літери гравця (вірні та невірні).
Структура проєкту
Файл	Призначення
`Common.h`	Загальні підключення бібліотек
`HangmanArt.h`	Enum стадій шибениці та ASCII-малюнки
`WordManager.h / .cpp`	Читання файлу слів, розшифрування, вибір випадкового слова
`Game.h / .cpp`	Основна логіка гри та статистика
`main.cpp`	Точка входу, запуск гри
`Words.txt`	Список слів у зашифрованому вигляді
Технології
C++ (Visual Studio)
ООП: класи, інкапсуляція, розділення відповідальності між класами
`std::vector`, `std::array`, `std::string`
`std::chrono` для заміру часу гри
Шифр Цезаря для зберігання слів у файлі
Як запустити
Відкрити рішення у Visual Studio.
Зібрати проєкт (Build → Build Solution).
Запустити (Ctrl+F5).
Вводити по одній літері, поки не буде відгадано слово або вичерпано спроби.
